# مدى — إدارة الشركة والمصنع

برنامج عربي لإدارة المبيعات والفواتير والعملاء والموظفين والأعمال والقبض والمصروفات، مع لوحة مؤشرات ورسوم بيانية. يشمل متابعة المعدّات وأوامر الإنتاج، وإضافة أقسام مخصصة دون إنشاء برنامج جديد.

## تشغيل نسخة ويندوز

1. نزّل ملف `Mada-Windows-x64-v1.0.0.zip` وفك ضغطه كاملًا.
2. افتح المجلد الناتج وشغّل `Mada.exe`.
3. احتفظ بكل الملفات الموجودة بجانب الملف التنفيذي؛ لا تنقله منفردًا.

تعمل النسخة على **Windows 10 أو 11 بنواة 64 بت**. لا تحتاج إلى تثبيت Node.js، أو فتح متصفح، أو الاتصال بالإنترنت أثناء الاستخدام. نسخة ويندوز تُبنى من بيئة التطوير؛ نجاح بنائها لا يعني أنها اختُبرت على جهاز ويندوز فعلي.

## أول استخدام

- تبدأ المساحة ببيانات تجريبية توضح طريقة عمل البرنامج. للبدء الفعلي، افتح **الإعدادات ← البيانات والنسخ الاحتياطي ← البدء بمساحة فارغة**. احفظ نسخة احتياطية أولًا إذا كانت هناك سجلات تريد الاحتفاظ بها.
- أدخل اسم الشركة والعنوان والهاتف والرقم الضريبي والعملة من **بيانات الشركة**.
- أضف العملاء والموظفين، ثم الأعمال أو المعدات وأوامر الإنتاج حسب احتياج نشاطك.
- أنشئ الفاتورة ببنودها وكمياتها وأسعارها، وحدد الخصم والضريبة، ثم افتحها للطباعة أو الحفظ بصيغة PDF من نافذة الطباعة.
- سجّل الأموال المستلمة في **القبض** واربطها بالفاتورة؛ تتحدث المبالغ المسددة والمتبقية تلقائيًا. سجّل الأموال المدفوعة في **المصروفات**.
- من **الإعدادات ← الأقسام والإضافات**، أنشئ قسمًا مثل الموردين أو قطع الغيار وحدد حقوله. يظهر القسم في القائمة الجانبية ويمكن إضافة سجلاته وتعديلها والبحث فيها.

## مكان البيانات والنسخ الاحتياطي

في تطبيق ويندوز تُحفظ البيانات محليًا ضمن `%APPDATA%\Mada`، في قاعدة IndexedDB للمتصفح المدمج. إغلاق البرنامج لا يحذف البيانات، ونقل مجلد البرنامج لا يغيّر مسار حفظها. لا تحذف مجلد بيانات المستخدم.

في نسخة المتصفح تُحفظ البيانات في المتصفح والجهاز وعنوان التطبيق المستخدمين. لا تنتقل سجلات المعاينة السحابية إلى جهازك تلقائيًا، وقد يؤدي مسح بيانات المتصفح أو تغيير عنوان التطبيق إلى فقد الوصول إليها.

لتنزيل ملف مستقل يحتوي كل البيانات، استخدم **الإعدادات ← البيانات والنسخ الاحتياطي ← تنزيل نسخة احتياطية**. احتفظ بنسخ دورية خارج مجلد البرنامج، ويفضل على وسيط آخر. لاسترجاع ملف، اختر **استرجاع من ملف** وراجع الملخص قبل تأكيد استبدال البيانات الحالية. النسخة الاحتياطية تتضمن بيانات الشركة والعملاء؛ احتفظ بها في مكان مناسب.

## حدود النسخة

هذه نسخة محلية لمستخدم واحد. لا توفر مزامنة بين الأجهزة أو صلاحيات متعددة للمستخدمين. سجلات الموظفين والمصروفات لا تمثل نظام مرتبات أو محاسبة قانونية متكاملًا، ومتابعة الإنتاج ليست نظام مخزون وتكلفة صناعية آليًا. الفواتير المطبوعة ليست ربطًا بمنظومة الفاتورة الإلكترونية أو إقرارًا بالامتثال الضريبي. الأقسام المخصصة سجلات نصية؛ ربطها بالحسابات أو تنفيذ حسابات آلية جديدة يحتاج تطويرًا إضافيًا.

## تشغيل المشروع للتطوير

المتطلبات: Node.js 24 وnpm. ثبّت الاعتماديات من ملف القفل:

```bash
npm ci
npm run dev
```

للبناء والتحقق:

```bash
npm test
npm run build
```

لتشغيل تطبيق سطح المكتب من المصدر بعد البناء:

```bash
npm run desktop
```

لبناء حزمة ويندوز المحمولة على بيئة التطوير:

```bash
npm run build
node scripts/package-windows.mjs
```

يتطلب التغليف اتصالًا لتنزيل إصدار Electron المطابق، وPython 3 لإنشاء الملف المضغوط. تبقى فحوص TLS والتحقق من تنزيل Electron مفعّلة. تظهر الحزمة والمجلد القابل للتشغيل داخل `release/`. الكود المصدري يستخدم React وTypeScript وVite؛ كل الخطوط والأصول مرفقة محليًا دون اعتماد على شبكة وقت التشغيل.

اختبارات الواجهة: `npm run test:e2e`؛ يلزم Chromium مثبت أو تنزيل متصفح Playwright. اختبار سطح المكتب في بيئة Linux: `npm run desktop:install` ثم `npm run test:desktop`، ويستخدم ملف مستخدم مؤقتًا معزولًا. يُختبر الحفظ بعد إغلاق التطبيق ونقل مجلده، وكذلك إخراج فاتورة PDF.
