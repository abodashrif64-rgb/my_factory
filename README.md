# مدى — إدارة الشركة والمصنع

برنامج عربي لإدارة المبيعات والمشتريات والفواتير والعملاء والموردين والموظفين والأعمال والقبض والمصروفات، مع لوحة مؤشرات ورسوم بيانية. يشمل متابعة المعدّات وأوامر الإنتاج، وإضافة أقسام مخصصة دون إنشاء برنامج جديد.

## تشغيل نسخة ويندوز

1. نزّل ملف `Mada-Windows-x64-v1.1.0.zip` وفك ضغطه كاملًا.
2. افتح المجلد الناتج وشغّل `Mada.exe`.
3. احتفظ بكل الملفات الموجودة بجانب الملف التنفيذي؛ لا تنقله منفردًا.

تعمل النسخة على **Windows 10 أو 11 بنواة 64 بت**. لا تحتاج إلى تثبيت Node.js، أو فتح متصفح، أو الاتصال بالإنترنت أثناء الاستخدام. نسخة ويندوز تُبنى من بيئة التطوير؛ نجاح بنائها لا يعني أنها اختُبرت على جهاز ويندوز فعلي.

## أول استخدام

- تبدأ المساحة ببيانات تجريبية توضح طريقة عمل البرنامج. للبدء الفعلي، افتح **الإعدادات ← البيانات والنسخ الاحتياطي ← البدء بمساحة فارغة**. احفظ نسخة احتياطية أولًا إذا كانت هناك سجلات تريد الاحتفاظ بها.
- أدخل اسم الشركة والعنوان والهاتف والرقم الضريبي والعملة من **بيانات الشركة**.
- أضف العملاء والموظفين، ثم الأعمال أو المعدات وأوامر الإنتاج حسب احتياج نشاطك.
- أنشئ الفاتورة ببنودها وكمياتها وأسعارها، وحدد الخصم والضريبة، ثم افتحها للطباعة أو الحفظ بصيغة PDF من نافذة الطباعة.
- سجّل الأموال المستلمة في **القبض** واربطها بالفاتورة؛ تتحدث المبالغ المسددة والمتبقية تلقائيًا. سجّل الأموال المدفوعة في **المصروفات**.
- من **الإعدادات ← الأقسام والإضافات**، أنشئ قسمًا مثل متابعة قطع الغيار وحدد حقوله ونوع كل حقل: نص أو رقم أو مبلغ أو تاريخ. ويمكن تعديل أنواع الحقول أو إضافة حقول إلى قسم موجود، مع التحقق من توافق السجلات الحالية. يظهر القسم في القائمة الجانبية ويمكن إضافة سجلاته وتعديلها والبحث فيها.

## المشتريات وحساب المورد

1. من **الموردون** أضف المورد وبيانات التواصل والرقم الضريبي إن وجد.
2. من **المشتريات ← فاتورة شراء جديدة** اختر المورد، ثم الأصناف والوحدات والكميات والأسعار. يُحسب الإجمالي بعد الخصم والضريبة تلقائيًا.
3. إذا دفعت عند الشراء، أدخل الدفعة الأولى؛ اتركها صفرًا للفاتورة الآجلة.
4. من تفاصيل الفاتورة اختر **تسجيل دفعة للمورد** لتسجيل كل سداد لاحق. يمكنك تصحيح دفعة مسجلة بالخطأ أو حذفها بعد التأكيد.
5. من المورد افتح **كشف الحساب** لمتابعة فواتيره والمدفوع والمتبقي، واطبعه أو احفظه PDF.

مدفوعات الموردين تدخل تلقائيًا في التدفق النقدي؛ لا تسجلها مرة ثانية كمصروف. الفاتورة الآجلة تُظهر مستحقًا للمورد فورًا، ويُخصم المبلغ من التدفق النقدي وقت السداد فقط.

## تحديث نسخة 1.0.0 مع الاحتفاظ ببياناتك

نزّل نسخة احتياطية من الإصدار القديم أولًا، ثم أغلقه تمامًا. فك حزمة 1.1.0 في مجلد جديد وافتح Mada.exe تحت نفس حساب ويندوز. مسار الحفظ ما زال `%APPDATA%\Mada` وتُقرأ بياناتك القديمة تلقائيًا. **لا تستخدم «البدء بمساحة فارغة» أثناء التحديث.**

تظل الأقسام المخصصة القديمة وسجلاتها موجودة، بما فيها أي قسم مشتريات نصي أنشأته سابقًا. القسم الجديد «المشتريات» مستقل؛ لم نحول النصوص القديمة إلى فواتير أو نحذفها. يمكن استخدام زر فتح المشتريات المتكاملة من القسم القديم.

بعد أول حفظ في النسخة الجديدة، يُرفع إصدار صيغة البيانات إلى 2. الإصدار القديم يرفض هذه الصيغة بدلًا من تجاهل بيانات المشتريات؛ استخدم النسخة الجديدة. يمكن استيراد نسخ احتياطية قديمة بصيغة 1 إلى النسخة الجديدة.

## مكان البيانات والنسخ الاحتياطي

في تطبيق ويندوز تُحفظ البيانات محليًا ضمن `%APPDATA%\Mada`، في قاعدة IndexedDB للمتصفح المدمج. إغلاق البرنامج لا يحذف البيانات، ونقل مجلد البرنامج لا يغيّر مسار حفظها. لا تحذف مجلد بيانات المستخدم.

في نسخة المتصفح تُحفظ البيانات في المتصفح والجهاز وعنوان التطبيق المستخدمين. لا تنتقل سجلات المعاينة السحابية إلى جهازك تلقائيًا، وقد يؤدي مسح بيانات المتصفح أو تغيير عنوان التطبيق إلى فقد الوصول إليها.

لتنزيل ملف مستقل يحتوي كل البيانات، استخدم **الإعدادات ← البيانات والنسخ الاحتياطي ← تنزيل نسخة احتياطية**. احتفظ بنسخ دورية خارج مجلد البرنامج، ويفضل على وسيط آخر. لاسترجاع ملف، اختر **استرجاع من ملف** وراجع الملخص قبل تأكيد استبدال البيانات الحالية. النسخة الاحتياطية تتضمن بيانات الشركة والعملاء؛ احتفظ بها في مكان مناسب.

## حدود النسخة

هذه نسخة محلية لمستخدم واحد. لا توفر مزامنة بين الأجهزة أو صلاحيات متعددة للمستخدمين. سجلات الموظفين والمصروفات لا تمثل نظام مرتبات أو محاسبة قانونية متكاملًا، ومتابعة الإنتاج ليست نظام مخزون وتكلفة صناعية آليًا. الفواتير المطبوعة ليست ربطًا بمنظومة الفاتورة الإلكترونية أو إقرارًا بالامتثال الضريبي. الأقسام المخصصة تدعم النصوص والأرقام والمبالغ والتواريخ وإجماليات الأعمدة؛ ربط حقولها بحسابات آلية أو إضافة تكاملات جديدة يحتاج تطويرًا إضافيًا. المشتريات لها قسم متكامل مستقل، ولا تنشئ حركة مخزون آلية.

## تشغيل المشروع للتطوير

المتطلبات: Node.js 24 وnpm. ثبّت الاعتماديات من ملف القفل:

```bash
npm ci
npm run dev
```

للبناء والتحقق:

```bash
npm test
npm run build
```

لتشغيل تطبيق سطح المكتب من المصدر بعد البناء:

```bash
npm run desktop
```

لبناء حزمة ويندوز المحمولة على بيئة التطوير:

```bash
npm run build
node scripts/package-windows.mjs
```

يتطلب التغليف اتصالًا لتنزيل إصدار Electron المطابق، وPython 3 لإنشاء الملف المضغوط. تبقى فحوص TLS والتحقق من تنزيل Electron مفعّلة. تظهر الحزمة والمجلد القابل للتشغيل داخل `release/`. الكود المصدري يستخدم React وTypeScript وVite؛ كل الخطوط والأصول مرفقة محليًا دون اعتماد على شبكة وقت التشغيل.

اختبارات الواجهة: `npm run test:e2e`؛ يلزم Chromium مثبت أو تنزيل متصفح Playwright. اختبار سطح المكتب في بيئة Linux: `npm run desktop:install` ثم `npm run test:desktop`، ويستخدم ملف مستخدم مؤقتًا معزولًا. يُختبر الحفظ بعد إغلاق التطبيق ونقل مجلده، وكذلك إخراج فاتورة PDF.
